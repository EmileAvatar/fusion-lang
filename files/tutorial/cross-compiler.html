Other languages through Fusion How it is named

Cross Compiler an idea

Code written in other languages, run through Fusion - one toolchain, one set of safety rules.

How it is named

Each language is a module named Lang.<Language>.Fusion - for example Lang.Python.Fusion; the library Fusion.Lang loads them.
