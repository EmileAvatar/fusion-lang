Ownership

One owner, one writer

Every value has one owner. Assigning it moves it, passing it lends it - so memory is freed exactly once, never too early, never forgotten, and without a garbage collector.

Moving

Car b = a hands the car over: b owns it, and a can't be used until it gets a new value. byVal makes a copy instead.

Example
class Car
    public string color
    constructor(string color)
        this.color = color

void function main()
    Car a = Car("red")
    Car b = a                     // with "move": b owns the car now
    // print(a.color) here: 'a' was moved to 'b' on line 8 - use byVal a for a copy
    a = Car("blue")               // a new value brings a back
    Car c = byVal b               // a copy: two cars
    c.color = "green"
    print("{a.color} {b.color} {c.color}")   // blue red green
blue red green

Borrowing

Passing a value to a function lends it for the call - it is back afterwards. A function that keeps what it is given (stores or returns it) takes it instead, and the call moves the argument.

One writer

A value several threads use gets exactly one writer - a service - so two threads can never change it at once.

A project chooses in fusion.toml: [memory] ownership = "strict" (the default - every rule) or "relaxed" (shared objects, the rules loosened). More pages to come.
