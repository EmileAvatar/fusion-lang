🏗️ Welcome to Fusion

Fusion is a configurable programming language. One language - and each project chooses how its code is written, how memory is managed and how strict the compiler is, in one settings file: fusion.toml.

Start learning ›

What is Fusion?

Fusion compiles to C and then to a native program - fast, small, with no virtual machine. It aims to be memory-safe and free of data races by construction, without a garbage collector by default.

Why Fusion?

Every language makes you choose: C is fast but unsafe, Python is easy but slow, Rust is safe but strict, Go is simple but restrictive. Fusion's goal is to remove that forced choice - reconfigure Fusion instead of switching languages when your project's needs change.

Major features

Configurable

Safety, memory, settings and backend chosen per project in fusion.toml.

Syntax without lock-in

Indentation, braces or End words - one meaning, your choice.

One owner, one writer

Every value has one owner; no crashes from freed memory, no leaks.

Services designed

Shared state without locks: no race conditions, no deadlocks by design.

Generics

One function or class for many types - copied per type, no run-time cost.

HIDL idea

Hardware described in Fusion - testbenches and more.

Cross compiler idea

Other languages run through Fusion: Lang.<Language>.Fusion.

Write it your way

Example
int function bigger(int a, int b)
    if a > b
        return a
    return b

void function main()
    print("{@1}", bigger(4, 9))   // 9
9
