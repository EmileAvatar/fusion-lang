What the columns mean

Kind
value: copied on assignment. ref: shared, and freed when the last place holding it lets go (Object_Lifetime.md).
Default
What a variable holds when it is declared without a value.
Min / Max
The range - for text and collections, the size limit.
Size
What the variable itself takes, in bytes. For a reference, the 8-byte pointer.
Can be null
Without any setting.
Status
built: works today. designed: decided, not built. planned: on the task list.

Open points this table brought up

  1. short and long are reserved words but not built - using one gives no clear "not built yet" error.
  2. money - decided (2026-10-29): a long of minor units, no currency (Task 47.2).
  3. An enum whose values carry fixed data (like a table of these types) - Task 47.3.
