# src/semantic/ - checking the AST

| File | What it does |
|---|---|
| `semantic_analyzer.py` | Runs the passes below in order and collects errors and warnings (entry point of this folder) |
| `number_patterns.py` | Checks `formatNumber` patterns written in the source (the same rules as the C runtime) |
| `heap_arrays.py` | Plain arrays that get a new size (Task 45.10, D.141): before names are resolved, an array replaced as a whole, an `int[]` result of any size and an unsized struct field become a heap array - a List block marked `array_form`, still acting as an array; a local of 2 or 3 dimensions given values of another shape lives on the heap as a growable one does, marked `plain_heap` (45.12e) |
| `many_dims.py` | Arrays of 2 and 3 dimensions (Task 45.12): the type rules (a mixin of the type checker) - declarations and nested values flattened in `[arrays] order`, one index per dimension, views, foreach, `rows` / `columns` / `depth` / `length`, parameters of any size, growable ones and `expand` (the `Dimension` enum, added when used); `setStorage` (the `Storage` enum, added when used; `mark_storage_calls` - placed right after the declaration, 45.15); `check_many_dims_uses` - every use not built yet an error |
| `generics.py` | Generic functions (Task 33.2a, D.166): `take_generic_functions` - before names are resolved, a function with type parameters (`<T>`, or T / K / V in its signature) is taken out of the program; `GenericsMixin.generic_call` - at a call the types are worked out (or read from `first<int>`) and a copy made once per set of types (`first__int`), registered and added to the program; generic structs (33.2b) - `struct_instance` makes `Pair__int__string` when a type (`Pair<int, string>`, through the name resolver) or a call (`Pair(1, "a")`) needs it; generic classes (33.2c) - the methods and constructors copied with it (`Box__int.take`); the analyzer names a copy as written in messages (`Box<int>`); conditions (33.2d, D.167) - `check_condition_declarations` (each names something that exists), `unmet_condition` (a type at a call or written `Box<Aircraft>` meets `extends` / `Number` / `int` / `implements`); `int... numbers` / `T... items` (33.2e) - `variadic_parameters` (last, a List inside), `pack_variadic` (the call's values one List, lent); a pack (33.2e2) - values of several types without a condition: `_pack_instance` a copy per combination, one parameter per value, `_unroll_pack` writes the loop out per value |
| `stack_arrays.py` | Arrays on the stack in bytes (Task 45.13, D.145): after type checking, a local array (or a struct holding one) above `[arrays] stackWarn` is a warning, above `stackLimit` an error |
| `null_guards.py` | The null guard (Task 52.8): runs first - `c?.f()` becomes an `if`, `c?.x ?? d` the conditional operator, a guarded test in a condition `(c is not null) and (...)`; a guarded value with no default is an error |
| `templates.py` | String templates (Task 29.3): runs first and expands every use - `greet(a)` becomes `format(<text>, a)`, a template passed where a function type is written becomes a lambda (`expand_templates`) |
| `struct_parents.py` | Structs building on structs (Task 32.8): gives `struct Employee implements Person` its Person part (`expand_struct_parents`, run before name resolution), and the type rules - inherited fields and methods, an Employee as a Person, constructors, a whole struct as text, `toCSV` (a mixin of the type checker) |
| `inferred.py` | `let` / `var` and match values (Task 46): the type from the value, a let or var set later (`check_set_once` - set before read, a let once), the type rules of a match that gives a value (a mixin of the type checker) |
| `readonly.py` | readonly parameters (Task 32.2e): after type checking, finds what each function does with each parameter (change, keep, pass on - following the calls) and reports any of it on a readonly one |
| `inheritance.py` | inheritance (Task 32.7): before interfaces - the parent's fields first, inherited functions, override / sealed / abstract checks, virtual functions through a hidden `X.virtual` table, super(...) via the parent's `init`, super.f() |
| `case_names.py` | `[source] caseSensitive = false` (Task 32.11): before anything rewrites the program, names that differ only in case (program, type members, a function's own) are errors, each pair once |
| `ownership.py` | `[memory] assignment = "move"` (Tasks 48.1, 48.2): after type checking, follows each variable along every path (if / match / loops twice / try) - a use after a move is an error; a function that keeps a parameter takes it; a local borrow freezes its owner until its last use |
| `interfaces.py` | interfaces (Task 32.5a): before names are resolved, checks what each interface builds on, gives it their functions, checks each class gives every function (public, same signature), records which answers each - and default methods behind a setting |
| `setup_blocks.py` | Form B on any variable (Task 32.2d): a local's set-up block becomes a block right after its declaration; checks a set-up block (local or class field) changes only its own variable |
| `statics.py` | A class's statics (Task 32.2c): each static becomes a module variable `Car.count` and the class's set-up (forms A, B, C) the function `Car.__setup` (`expand_statics`, before name resolution); after type checking `static_setup_order` orders the set-ups by dependency and reports a circle |
| `class_rules.py` | Class rules over the whole program (Task 32.10d): a warning for each circle of classes whose objects can hold each other - never freed under OWNERSHIP (`check_class_cycles`); constructors (32.2b); `[visibility] required` - a missing level is an error (`check_visibility_written`, 32.2h) |
| `enums.py` | Enums (Task 25): turns enum types / `Color.Red` / `Color.values()` into enum nodes before checking (`normalize_enums`), checks declarations, and the type rules (a mixin of the type checker) |
| `error_rules.py` | Errors (Task 26): turns `Error` types / `Error(...)` into error nodes (`normalize_errors`), and the type rules - fields, `if err`, `return Error(...)` (a mixin of the type checker) |
| `collection_rules.py` | Type rules for `List<T>` and `Map<K, V>` (Tasks 18.5.1-2): literals, methods, `for x in` - a mixin of the type checker |
| `name_resolver.py` | Registers built-ins (and their optional arguments, `BUILTIN_DEFAULTS`), structs, functions and variables; reports undefined/duplicate names and unknown types |
| `type_checker.py` | Checks every expression and statement's types; struct, string, array and call rules; writes `inferred_type` |
| `control_flow_validator.py` | Checks returns on every path, and `break`/`continue` only inside loops |
| `entry_point_validator.py` | Checks there is exactly one valid `main` function |
| `symbol.py` | `Symbol` (a named thing) and `Scope` (one block's names) |
| `symbol_table.py` | The stack of scopes: enter/exit blocks, define and look up names |
| `errors.py` | `SemanticError`, used for both errors and warnings |
| `__init__.py` | Exports `SemanticAnalyzer` |
